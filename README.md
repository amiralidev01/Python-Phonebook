# Python Phone Book 📒

A simple command-line phone book application built with Python. This is my first Python project, created to practice programming fundamentals, functions, loops, conditional statements, and file handling.

## ✨ Features

- **Add Contacts:** Save a contact's name and phone number.
- **Search Contacts:** Find a contact by name.
- **Delete Contacts:** Remove a contact from the phone book.
- **Show All Contacts:** Display all saved contacts.
- **File Storage:** Store contact information in a text file.

## 🛠️ Technologies Used

- Python 3
- Built-in `os` module
- File handling (`open`, `read`, `write`)
- Functions, loops, and conditional statements

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/amiralidev01/Python-Phonebook.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Python-Phonebook
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## 📋 How to Use

When you run the program, a menu appears with the following options:

```text
=============================Phone Book=============================
1-Add
2-Search
3-Delete
4-Show
0-Exit
```

Enter the number of your desired option and follow the instructions.
